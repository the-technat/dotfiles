# Coding Conventions (global)

- Follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/)
- Always link stories at the end of a commit in brackets: (CLOUD-1234)
- Name branches after the story: CLOUD-1234/my-feature
- For all commits you do yourself: Add a line `Co-authored-by: <Model>` so that it's clear who commited what
